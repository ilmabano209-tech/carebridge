# CareBridge - Senior Care Hub 🛡️❤️

A comprehensive health analytics and remote monitoring platform engineered to bridge the communication and healthcare gap between independent senior citizens and their families.

## 🔗 Live Deployments
* **Live Website Link:**https://senior-care-hub-42.preview.emergentagent.com/?utm_source=share

---

## 🚀 Key Technical Features

* **Senior-Friendly Health Dashboard:** Clean visual layout tailored for elderly users to log complex health statistics without confusion.
* **Smart Health Trackers:** Specialized dynamic loggers for monitoring daily Blood Pressure (Systolic/Diastolic) and Blood Glucose levels.
* **One-Tap Emergency SOS Alert:** A programmatic zero-trust security gate that triggers instant real-time alerts to family members during medical emergencies.
* **Live Doctor Appointment Scheduler:** A fully functional scheduling module integrated with customized date/time pickers and automated upcoming appointment cards.
* **Medication Logging System:** A simple digital logbook to track daily medicine intake and avoid missing critical doses.

---

## 🛠️ Engineering Tech Stack
* **Frontend Architecture:** React.js, Tailwind CSS, Vite
* **Component Library:** Lucide React (for accessible typography and visual anchors)
* **Design Philosophy:** Human-centric UI, high contrast text elements, and fully responsive layouts.
